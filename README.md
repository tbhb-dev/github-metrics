# github-metrics

A planned containerized Go service that turns GitHub pull request activity into OpenTelemetry traces and metrics, served at github-metrics.tbhb.dev.

This is a work in progress. Its design is in tbhb-dev/wiki, under drafts/github-metrics.

Licensed under Apache-2.0.

## Development

Bazel builds and tests the project. See `AGENTS.md` for the commands.
